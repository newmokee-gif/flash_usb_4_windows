# WinUSB Creator 0.3.3 — English interface and documentation

The application interface, buttons, progress messages, errors and safety confirmations are now in English on Windows, Linux and macOS. README, catalogue documentation and documented historical release descriptions have also been translated.

The startup chooser offers **Windows** and **GNU/Linux**. Russian and English Windows installation images remain available, including all four Windows 10 variants. The catalogue retains **60 distributions, 77 image variants and 17 ARM64 variants**. Download sources, torrent priority, official checksum verification and USB erasure confirmation are unchanged.

## Applications

| System | File |
| --- | --- |
| Windows x64 | `WinUSB-Creator-Windows-x64.exe` |
| Windows 11 ARM64 | `WinUSB-Creator-Windows-ARM64.exe` |
| macOS 15+ Intel | `WinUSB-Creator-macOS-Intel.dmg` |
| macOS 15+ Apple Silicon | `WinUSB-Creator-macOS-AppleSilicon.dmg` |
| Linux x64 | `flash-usb-v0.3.3-x86_64.AppImage` |
| Linux ARM64 | `flash-usb-v0.3.3-aarch64.AppImage` |
| Debian x64/ARM64 | `flash-usb_0.3.3_all.deb` |
| Fedora x64/ARM64 | `flash-usb-0.3.3-1.noarch.rpm` |

All eight applications are built from the same tag. Publication requires every platform's checks, catalogue verification and re-verification of uploaded release assets. `SHA256SUMS.txt` and `RELEASE-PROVENANCE.json` accompany the applications. Earlier release binaries are not replaced by this translation.

The Windows EXE is standalone. On Mac, move the application from the DMG into Applications. AppImage needs glibc 2.36+ and the documented system utilities; DEB/RPM install dependencies through the package manager. See the [English instructions](https://github.com/newmokee-gif/flash_usb_4_windows/blob/v0.3.3/README.md).

**Writing erases all data on the selected USB drive.** Physical USB writing and booting on target hardware have not been tested. Windows applications are unsigned; macOS applications are ad-hoc signed without Apple notarization. Automated checks do not guarantee bug-free operation or compatibility with every computer.
