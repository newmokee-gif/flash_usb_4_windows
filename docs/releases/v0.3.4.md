# WinUSB Creator 0.3.4 — redesigned interface and new icon

The startup chooser and both installation modes now share a consistent visual style, numbered steps, clearer image and USB sections, prominent download/write actions and a readable activity log. Scrolling and keyboard focus navigation keep controls reachable in smaller windows. WinGet, Homebrew and dependency installation remain visible.

The new blue USB-and-arrow icon is used by application windows, Windows executables, macOS bundles and Linux launchers. The underlying download, checksum verification and USB confirmation logic is retained. Russian and English Windows images and the 60-distribution Linux catalogue remain available.

## Ready-to-run applications

| Platform | File |
| --- | --- |
| Windows x64 | `WinUSB-Creator-Windows-x64.exe` |
| Windows 11 ARM64 | `WinUSB-Creator-Windows-ARM64.exe` |
| macOS 15+ Intel | `WinUSB-Creator-macOS-Intel.dmg` |
| macOS 15+ Apple Silicon | `WinUSB-Creator-macOS-AppleSilicon.dmg` |
| Linux x64 | `flash-usb-v0.3.4-x86_64.AppImage` |
| Linux ARM64 | `flash-usb-v0.3.4-aarch64.AppImage` |
| Debian x64/ARM64 | `flash-usb_0.3.4_all.deb` |
| Fedora x64/ARM64 | `flash-usb-0.3.4-1.noarch.rpm` |

All eight applications are built from the same tag. Publication requires successful native platform checks, catalogue verification and re-downloading the uploaded release files to verify their SHA-256 hashes. Checksums and build provenance are attached. Previous binaries are retained rather than overwritten.

Windows EXEs are standalone. On Mac, move the application from the DMG into Applications. AppImage requires glibc 2.36+ and the documented system tools; DEB/RPM install dependencies through the package manager. See the [instructions](https://github.com/newmokee-gif/flash_usb_4_windows/blob/v0.3.4/README.md).

**Writing erases the selected USB drive.** Physical USB writing and target-hardware booting have not been tested. Windows applications are unsigned; macOS applications are ad-hoc signed without Apple notarization. Passing automated checks does not guarantee bug-free operation or hardware compatibility.
