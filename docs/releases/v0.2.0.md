# WinUSB Creator 0.2.0 — Windows, Linux и macOS

Единый релиз со всеми восемью готовыми сборками. Программа создаёт установочную USB-флешку из Windows ISO. Архитектура приложения относится к компьютеру, на котором вы его запускаете; архитектуру ISO выбирайте для целевого компьютера.

## Установка

**Windows x64:** скачайте и запустите `WinUSB_Creator.exe`. Это сохранённая оригинальная portable-сборка, а не новая пересборка Windows x64.

**Windows 11 ARM64:** полностью распакуйте ZIP и запустите `WinUSB-Creator-Windows-ARM64.exe`; каталог `_internal` должен оставаться рядом. Python/Tk включены. Для автоматической загрузки ISO нужен отдельно установленный нативный `aria2c` ARM64; для локального ISO он не требуется. ZIP не подписан цифровой подписью.

**Debian / Fedora:** установите скачанный пакет — системные зависимости установит пакетный менеджер:

```sh
# Debian
sudo apt install ./flash-usb_0.2.0.linux.2_all.deb
# Fedora
sudo dnf install ./flash-usb-0.2.0-0.2.linux.noarch.rpm
```

Откройте WinUSB Creator в меню приложений или выполните `flash-usb`. DEB (`all`) и RPM (`noarch`) — готовые пакеты Python-приложения для обеих архитектур, не автономные бинарники.

**Linux AppImage:** Python/Tk включены; требуется glibc 2.36+ и системные утилиты записи из инструкции. Для ARM64 замените `x86_64` на `aarch64`:

```sh
chmod +x flash-usb-v0.2.0-linux.2-x86_64.AppImage
./flash-usb-v0.2.0-linux.2-x86_64.AppImage
# Без FUSE:
./flash-usb-v0.2.0-linux.2-x86_64.AppImage --appimage-extract-and-run
```

**macOS:** распакуйте ZIP, перенесите целиком `WinUSB Creator.app` в «Программы», установите `brew install wimlib`. Python/Tk включены. Приложения имеют техническую ad-hoc подпись, но не Developer ID и не нотариализацию Apple. Если Gatekeeper блокирует запуск, проверьте SHA-256 и для доверенного приложения используйте «Открыть всё равно» в «Системные настройки → Конфиденциальность и безопасность». Не отключайте защиту системы целиком.

## Проверки и ограничения

- Перенесённые файлы сверены с оригинальными SHA-256; файлы нового релиза повторно скачаны и проверены перед переключением публикаций.
- Ранее выполнены Linux-проверки в Debian/Fedora/Arch, нативные ARM64-проверки Debian/Fedora и Windows 11, а также нативные проверки macOS Intel/Apple Silicon. Они включают применимые к платформе тесты GUI/CLI, архитектуры, упаковки и операций WIM. Windows x64 — историческая сборка; новые ARM64-тесты не подтверждают её работу.
- **Физическая запись USB, загрузка на целевом оборудовании и интерактивные диалоги повышения прав не проверены. Отсутствие ошибок не гарантируется.** Запись удаляет все данные выбранной флешки; заранее сделайте резервные копии.
- Linux и macOS создают UEFI-установщик; Legacy BIOS для них не заявляется. macOS-приложение не устанавливает macOS и не добавляет Apple Silicon возможность нативной загрузки Windows с USB.
- 32-битный ARM не поддерживается; Arch Linux ARM не проверен. AppImage не предназначен для musl/Alpine.

## Что объединено

Этот обычный релиз заменяет публичные страницы прежних релизов `release` и `v0.2.0-linux.2`. Они переведены в черновики: теги и оригинальные файлы сохранены. Предварительные обозначения в именах и внутренние версии пакетов оставлены, чтобы не менять уже проверенные бинарные файлы. Это объединение публикаций, а не повторная сборка всех платформ.

`RELEASE-PROVENANCE.json` содержит исходные релизы, их примечания, данные файлов и контрольные суммы. Сохранены также исходные файлы `SHA256SUMS-*`, на которые ссылаются инструкции внутри ZIP. Актуальный исходный архив соответствует новому тегу; точные исторические исходники отдельных бинарных сборок указаны в их происхождении, где доступны. В частности, Windows/Linux ARM64 собраны из `8c48d00b5de9cca5fa711433f87b8ddd674b17e8`, а macOS — из `fe57a83b2a2443fcdb1eb3e78ffc6186d40925f1`.

Для Linux проверьте скачанные файлы в отдельной папке командой `sha256sum --ignore-missing -c SHA256SUMS.txt`. Для macOS используйте `shasum -a 256 ИМЯ_ФАЙЛА`, для Windows — `Get-FileHash .\ИМЯ_ФАЙЛА -Algorithm SHA256` и сравните результат со строкой в `SHA256SUMS.txt`.
