# WinUSB Creator 0.3.1 — prominent component installation buttons

WinGet and Homebrew installation buttons are larger and grouped in an explanatory panel. In GNU/Linux mode on Linux, dependency installation moves to the top of the window. Automatic component downloads and system installation confirmation are unchanged; WinGet installation does not use Microsoft Store.

## Ready-to-run applications

| System | File |
|---|---|
| Windows x64 | `WinUSB-Creator-Windows-x64.exe` |
| Windows 11 ARM64 | `WinUSB-Creator-Windows-ARM64.exe` |
| macOS 15+ Intel | `WinUSB-Creator-macOS-Intel.dmg` |
| macOS 15+ Apple Silicon | `WinUSB-Creator-macOS-AppleSilicon.dmg` |
| Linux x64 | `flash-usb-v0.3.1-x86_64.AppImage` |
| Linux ARM64 | `flash-usb-v0.3.1-aarch64.AppImage` |
| Debian x64/ARM64 | `flash-usb_0.3.1_all.deb` |
| Fedora x64/ARM64 | `flash-usb-0.3.1-1.noarch.rpm` |

All eight applications are rebuilt from one tag. Publication is allowed only after all platform checks, image catalogue checks and uploaded-file checksum verification pass. SHA-256 checksums and build provenance accompany the release.

The Windows EXE is standalone; on Mac, move the application from the DMG into Applications. AppImage requires glibc 2.36+ and system utilities; DEB/RPM install dependencies through the package manager. Instructions: [README](https://github.com/newmokee-gif/flash_usb_4_windows/blob/v0.3.1/README.md).

Windows applications are unsigned; macOS uses ad-hoc signing without Apple notarization. Physical USB writing and booting on real hardware have not been tested. Writing erases the selected drive. These checks do not guarantee the absence of all bugs.
