# WinUSB Creator 0.3.1 — заметные кнопки установки компонентов

Кнопки установки WinGet и Homebrew увеличены и выделены в отдельный блок с пояснением. В режиме ГНУ/Линукс на Linux установка зависимостей вынесена в верхнюю часть окна. Автоматическая загрузка компонентов и подтверждение системной установки не изменены; Microsoft Store для установки WinGet не используется.

## Готовые приложения

| Система | Файл |
|---|---|
| Windows x64 | `WinUSB-Creator-Windows-x64.exe` |
| Windows 11 ARM64 | `WinUSB-Creator-Windows-ARM64.exe` |
| macOS 15+ Intel | `WinUSB-Creator-macOS-Intel.dmg` |
| macOS 15+ Apple Silicon | `WinUSB-Creator-macOS-AppleSilicon.dmg` |
| Linux x64 | `flash-usb-v0.3.1-x86_64.AppImage` |
| Linux ARM64 | `flash-usb-v0.3.1-aarch64.AppImage` |
| Debian x64/ARM64 | `flash-usb_0.3.1_all.deb` |
| Fedora x64/ARM64 | `flash-usb-0.3.1-1.noarch.rpm` |

Все восемь приложений собираются заново из одного тега. Публикация разрешена только после успешных проверок всех платформ, каталога образов и контрольных сумм загруженных файлов. SHA-256 и происхождение сборок приложены к релизу.

Windows EXE запускается самостоятельно; на Mac перенесите приложение из DMG в Applications. AppImage требует glibc 2.36+ и системных утилит; DEB/RPM устанавливают зависимости через пакетный менеджер. Инструкции: [README](https://github.com/newmokee-gif/flash_usb_4_windows/blob/v0.3.1/README.md).

Windows-приложения не подписаны, macOS использует ad-hoc подпись без нотариализации Apple. Физическая запись USB и загрузка на реальном оборудовании не проверены. Запись удаляет данные выбранного накопителя. Проверки не являются гарантией отсутствия всех ошибок.
