# WinUSB Creator 0.3.2 — ещё 30 дистрибутивов

Каталог расширен с 30 до **60 дистрибутивов**: **77 образов, включая 17 ARM64-вариантов**. Архитектуры и редакции не считаются отдельными дистрибутивами.

Добавлены EndeavourOS, Artix Linux, Garuda Linux, antiX, Linux Lite, deepin, SparkyLinux, Bazzite, Tails, Rescuezilla, SystemRescue, Proxmox VE, Slint, Zorin OS, PureOS, Nobara Linux, Solus, MX Linux, Peppermint OS, Archcraft, Calculate Linux, Ultramarine Linux, Oracle Linux, Puppy Linux, GParted Live, Chimera Linux, openEuler, Vanilla OS, Rhino Linux и Parrot OS.

Официальные торренты имеют приоритет, при их отсутствии или недоступности используется официальный HTTPS-источник. Перед записью обязательна проверка SHA-256/SHA-512. Для Tails выбирается USB IMG; суммы GParted разделяются по алгоритмам, без смешения SHA-256 с BLAKE3. ARM64 добавлен только при наличии соответствующего установочного образа; поддержка конкретной платы и прошивки зависит от дистрибутива.

## Готовые приложения

| Система | Файл |
|---|---|
| Windows x64 | `WinUSB-Creator-Windows-x64.exe` |
| Windows 11 ARM64 | `WinUSB-Creator-Windows-ARM64.exe` |
| macOS 15+ Intel | `WinUSB-Creator-macOS-Intel.dmg` |
| macOS 15+ Apple Silicon | `WinUSB-Creator-macOS-AppleSilicon.dmg` |
| Linux x64 | `flash-usb-v0.3.2-x86_64.AppImage` |
| Linux ARM64 | `flash-usb-v0.3.2-aarch64.AppImage` |
| Debian x64/ARM64 | `flash-usb_0.3.2_all.deb` |
| Fedora x64/ARM64 | `flash-usb-0.3.2-1.noarch.rpm` |

Все восемь приложений пересобраны из одного тега. Публикация требует успешных проверок каждой платформы, доступности образов каталога, официальных контрольных сумм и повторной проверки загруженных файлов релиза. SHA-256 и происхождение приложений приложены к релизу.

Windows EXE запускается самостоятельно; на Mac перенесите приложение из DMG в Applications. AppImage требует glibc 2.36+ и системных утилит; DEB/RPM устанавливают зависимости через пакетный менеджер. Инструкции: [README](https://github.com/newmokee-gif/flash_usb_4_windows/blob/v0.3.2/README.md). [Источники каталога](https://github.com/newmokee-gif/flash_usb_4_windows/blob/v0.3.2/docs/distro-sources.md).

Windows-приложения не подписаны, macOS использует ad-hoc подпись без нотариализации Apple. Физическая запись USB и загрузка на реальном оборудовании не проверены. Запись удаляет данные выбранного накопителя. Успешные проверки не гарантируют отсутствие всех ошибок или совместимость каждого образа с любым компьютером.
