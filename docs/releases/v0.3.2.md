# WinUSB Creator 0.3.2 — 30 more distributions

The catalogue expands from 30 to **60 distributions**: **77 images, including 17 ARM64 variants**. Architectures and editions are not counted as separate distributions.

Added EndeavourOS, Artix Linux, Garuda Linux, antiX, Linux Lite, deepin, SparkyLinux, Bazzite, Tails, Rescuezilla, SystemRescue, Proxmox VE, Slint, Zorin OS, PureOS, Nobara Linux, Solus, MX Linux, Peppermint OS, Archcraft, Calculate Linux, Ultramarine Linux, Oracle Linux, Puppy Linux, GParted Live, Chimera Linux, openEuler, Vanilla OS, Rhino Linux and Parrot OS.

Official torrents take priority, with official HTTPS fallback when missing or unavailable. SHA-256/SHA-512 verification is mandatory before writing. Tails uses USB IMG; GParted checksums are separated by algorithm, without confusing SHA-256 with BLAKE3. ARM64 is offered only where installation images exist; board and firmware support depends on the distribution.

All eight applications are rebuilt from one tag. Publication requires successful platform checks, catalogue availability and official checksum validation, and re-verification of uploaded release assets. SHA-256 checksums and build provenance accompany the release.

The Windows EXE is standalone; on Mac, move the application from the DMG into Applications. AppImage requires glibc 2.36+ and system utilities; DEB/RPM install dependencies through the package manager. Instructions: [README](https://github.com/newmokee-gif/flash_usb_4_windows/blob/v0.3.2/README.md). [Catalogue sources](https://github.com/newmokee-gif/flash_usb_4_windows/blob/v0.3.2/docs/distro-sources.md).

Windows applications are unsigned; macOS uses ad-hoc signing without Apple notarization. Physical USB writing and booting on real hardware have not been tested. Writing erases the selected drive. Passing checks does not guarantee the absence of bugs or compatibility of every image with every computer.
