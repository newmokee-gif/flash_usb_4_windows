New package-manager installation buttons: **Homebrew** on macOS and **WinGet** on Windows, with a button to check availability. Mac opens the official installer in Terminal; Windows installs Microsoft files with SHA-256 and signature verification. Complete installation in the window that opens.

| System | File in Assets |
| --- | --- |
| Windows Intel/AMD x64 | `WinUSB-Creator-Windows-x64.zip` |
| Windows 11 ARM64 | `WinUSB-Creator-Windows-ARM64.zip` |
| macOS 15+ Apple Silicon | `WinUSB-Creator-macOS-AppleSilicon.zip` |
| macOS 15+ Intel | `WinUSB-Creator-macOS-Intel.zip` |
| Debian x64/ARM64 | `flash-usb_0.2.0.linux.2_all.deb` |
| Fedora x64/ARM64 | `flash-usb-0.2.0-0.2.linux.noarch.rpm` |
| Linux x64, including Arch | `flash-usb-v0.2.0-linux.2-x86_64.AppImage` |
| Linux ARM64 | `flash-usb-v0.2.0-linux.2-aarch64.AppImage` |

Windows: extract the complete ZIP and run the EXE inside; keep `_internal` alongside it. macOS: move the .app into Applications. Python/Tk are included. After installing Homebrew, run `brew install wimlib`. WinGet alone does not install aria2; local Windows ISOs can be used without aria2.

The four desktop builds are tested natively for architecture, GUI startup and the new buttons. Homebrew and WinGet installers are not automatically executed in CI. Linux assets are retained unchanged from v0.2.0. Combined checksums: `SHA256SUMS.txt`; provenance: `RELEASE-PROVENANCE.json`. Current source archive: `flash-usb-v0.2.1-source.tar.gz`.

macOS applications are ad-hoc signed without Apple notarization; Windows builds are unsigned. Physical USB writing and hardware booting have not been tested. Writing erases the selected drive. Linux requires glibc 2.36+ for AppImage and the system utilities in the [instructions](https://github.com/newmokee-gif/flash_usb_4_windows/blob/v0.2.1/README.md).
