Новые кнопки установки пакетных менеджеров: **Homebrew** на macOS и **WinGet** на Windows. Рядом — кнопка проверки наличия менеджера. На Mac открывается официальный установщик в Терминале, на Windows — установка файлов Microsoft с проверкой SHA-256 и цифровой подписи. Завершите установку в открывшемся окне.

| Система | Файл в Assets |
| --- | --- |
| Windows Intel/AMD x64 | `WinUSB-Creator-Windows-x64.zip` |
| Windows 11 ARM64 | `WinUSB-Creator-Windows-ARM64.zip` |
| macOS 15+ Apple Silicon | `WinUSB-Creator-macOS-AppleSilicon.zip` |
| macOS 15+ Intel | `WinUSB-Creator-macOS-Intel.zip` |
| Debian x64/ARM64 | `flash-usb_0.2.0.linux.2_all.deb` |
| Fedora x64/ARM64 | `flash-usb-0.2.0-0.2.linux.noarch.rpm` |
| Linux x64, включая Arch | `flash-usb-v0.2.0-linux.2-x86_64.AppImage` |
| Linux ARM64 | `flash-usb-v0.2.0-linux.2-aarch64.AppImage` |

Windows: полностью распакуйте ZIP и запустите EXE внутри папки; сохраните `_internal` рядом. macOS: перенесите .app в «Программы». Python/Tk включены. После установки Homebrew установите `brew install wimlib`. WinGet сам по себе не устанавливает aria2; локальный Windows ISO можно использовать без aria2.

Четыре desktop-сборки проверяются нативно: архитектуры, запуск GUI и наличие новых кнопок. Установщики Homebrew и WinGet автоматически в CI не запускаются. Linux-файлы сохраняются без изменения из v0.2.0. Общие контрольные суммы — `SHA256SUMS.txt`, происхождение — `RELEASE-PROVENANCE.json`. Исходники текущей версии — `flash-usb-v0.2.1-source.tar.gz`.

macOS-приложения имеют ad-hoc подпись без нотариализации Apple; Windows-сборки не подписаны. Физическая запись USB и загрузка на оборудовании ещё не проверены. Запись удаляет данные выбранного накопителя. Требования Linux: glibc 2.36+ для AppImage и системные утилиты из [инструкции](https://github.com/newmokee-gif/flash_usb_4_windows/blob/v0.2.1/README.md).
