## Windows or GNU/Linux

At startup, select which operating system to install on USB. Windows opens the familiar interface. GNU/Linux opens the distribution catalogue with available x64/ARM64 editions, official torrent or HTTPS downloads, image verification and byte-for-byte USB writing.

Windows 10 now has four variants: x64 RU/EN and x86 RU/EN. Windows 11 x64/ARM64 RU/EN remain available.

## Writing Linux images

Official sources and supported editions are listed in the [catalogue](https://github.com/newmokee-gif/flash_usb_4_windows/blob/v0.3.0/docs/distro-sources.md). BitTorrent takes priority: aria2 is bundled in DMG/AppImage, installed as a dependency for DEB/RPM, and downloaded automatically with SHA-256 verification on Windows. On Windows 11 ARM64, the x64 helper under OS emulation requires separate consent; the application is native ARM64. Unavailable torrents fall back to the official HTTPS server. ARM64 is shown only where an installation image exists. Raspberry Pi and other specialized boards require compatible images and firmware.

Checksums are verified before writing. Linux mode writes the complete image with its partition table, then reads the written bytes back. Confirm the exact USB drive before writing. **All data on the selected USB drive will be erased.**

System, internal and busy disks are blocked. Automated checks do not replace physical boot testing on your hardware. Windows EXEs are not Authenticode-signed; macOS uses ad-hoc signing without Apple notarization. ARM64, Secure Boot and BIOS/UEFI compatibility depend on the selected image and target computer.
