## Windows или ГНУ/Линукс

При запуске выберите, какую систему будете устанавливать на флешку. «Виндовс» открывает привычный интерфейс. «ГНУ/Линукс» открывает каталог дистрибутивов с доступными x64/ARM64 редакциями, загрузкой через официальный torrent или HTTPS, проверкой образа и побайтной записью на USB.

Windows 10 теперь имеет четыре варианта: x64 RU/EN и x86 RU/EN. Windows 11 x64/ARM64 RU/EN сохранены.

## Запись Linux

Официальные источники и поддерживаемые редакции перечислены в [каталоге](https://github.com/newmokee-gif/flash_usb_4_windows/blob/v0.3.0/docs/distro-sources.md). BitTorrent имеет приоритет: aria2 включён в DMG/AppImage, устанавливается пакетным менеджером для DEB/RPM и автоматически загружается с проверкой SHA-256 в Windows. На Windows 11 ARM64 использование x64-помощника через эмуляцию ОС требует отдельного согласия; приложение нативное ARM64. При недоступности торрента есть загрузка с официального HTTPS-сервера. ARM64 показывается только при наличии соответствующего установочного образа. Устройства Raspberry Pi и другие специализированные платы требуют совместимого образа и прошивки.

Проверка контрольной суммы выполняется до записи. Linux-режим записывает образ целиком с таблицей разделов, затем считывает записанные байты обратно. Перед записью нужно подтвердить точный USB-диск. **Все данные на выбранной флешке будут удалены.**

Системные/внутренние/занятые диски блокируются. Автоматические проверки не заменяют физическую проверку загрузки на вашем оборудовании. Windows EXE не имеет Authenticode-подписи, macOS использует ad-hoc подпись без нотариализации Apple. Совместимость ARM64, Secure Boot и BIOS/UEFI определяется выбранным образом и целевым компьютером.
